Single source of truth for all AeroFly frontend work. Every component implemented in the app MUST be based on a section of this kit. If a component is missing, add it here first.

15bChart Thumbnail Grid

Grouped thumbnail grid used on the aerodrome detail page. Each card = chart-type badge, fit-contained preview over white, title (2-line clamp), AIRAC footer. Click opens the zoom viewer (§19). Keyboard: Tab + arrow-keys navigate, Enter / Space open, Esc in viewer returns focus to the opened card.

Nur als Referenz — nicht für operative Nutzung. AIRAC-Zyklus 2026-04
