Nach Diskussion des Originalplans hat der Auftraggeber die Pipeline auf zwei Vision-Provider beschränkt (Claude Sonnet 4.6 + OpenAI GPT-4o). Die folgenden Anpassungen gelten gegenüber §04 – §05 des Originalplans:

  • Quellen: ausschließlich Claude Vision + OpenAI Vision. HTML Re-Scrape, Tesseract als Votum fallen weg.
  • Tesseract bleibt — aber als Grounding-Check, nicht als Votum. Nach jeder 2-von-2-Übereinstimmung wird die Bbox mit Tesseract ausgelesen und geprüft, ob der Wert dort literalisch vorkommt. Fehlende Bestätigung → fail-closed.

01Executive summary

  • Primärer Satz: kein Aerodrome-Feld wird je aus einer einzelnen LLM-Antwort im UI sichtbar.
  • Konsensmodell: pro Feld laufen bis zu vier unabhängige Quellen (Claude Vision · zweiter LLM · Tesseract-OCR auf LLM-Bbox · HTML re-scrape). Persistierung nach Risikoklasse (2-/3-von-3).
  • Fail-closed: Dissens oder Constraint-Verletzung → null, Feld erscheint als "—".
  • Human-in-loop Gate: Critical-Klasse (Frequenzen, Runway-Länge, Runway-Heading) ist im öffentlichen UI nur nach menschlicher Bestätigung sichtbar.
  • Lazy: Extraktion läuft erst, wenn ein Flugplatz erstmals aufgerufen wird; Ergebnis ist unveränderlich persistiert, AIRAC-bezogen invalidiert.
  • Kosten: ≈ 0,04 € pro erstmals aufgerufenen Flugplatz, einmalig pro AIRAC-Zyklus; Gesamt < 20 € / Zyklus falls alle 433 besucht.
  • Vollständiger Audit-Trail: jede Extraktion (erfolgreich oder verworfen) in append-only Tabelle; Raw-JSON + Bbox + Modell-/Prompt-Version.
  • GA-Gate: kein öffentlicher Launch ohne Safety-Sign-Off (Golden-F1, Adversarial-Fixtures, Top-10-Manual-Review).

Consensus-Engine (pseudo)

def reach_consensus(field: str, risk: RiskClass,
                     a: Extraction, b: Extraction,
                     c: OcrResult, d: HtmlResult | None) -> Decision:

    votes = []
    if a.value is not None: votes.append(("A", a.value))
    if b.value is not None: votes.append(("B", b.value))
    if c.value is not None: votes.append(("C", c.value))
    if d is not None and d.value is not None: votes.append(("D", d.value))

    # D trumps everything if present AND consistent with at least one other
    if d is not None:
        agreers = [s for s, v in votes if s != "D" and normalize(v, field) == normalize(d.value, field)]
        if len(agreers) >= 1:
            return Decision(value=d.value, consensus="html-anchored", sources=["D"] + agreers)
        return Decision(value=None, consensus="html-vs-others", sources=votes)

    # Otherwise: majority on normalized values
    groups = group_by(votes, lambda v: normalize(v[1], field))
    best = max(groups.values(), key=len)

    required = 3 if risk is RiskClass.CRITICAL else 2
    if len(best) >= required:
        # Domain constraint + unit check must still pass
        v = best[0][1]
        if not domain_ok(field, v) or not unit_ok(field, v):
            return Decision(value=None, consensus="constraint-violation", sources=votes)
        return Decision(value=v, consensus=f"{len(best)}-of-{len(votes)}", sources=[s for s,_ in best])

    return Decision(value=None, consensus="disagreement",
                    sources=votes, needs_review=(risk is RiskClass.CRITICAL))

14Go/No-Go-Gates

Gate α — nach Spike (Phase 0)

  • F1 ≥ 0.95 auf NORMAL auf 5 Aerodromes
  • 3-Quellen-Konsens tatsächlich erreicht auf ≥ 80 % der Felder
  • Kosten < $0.10 pro Aerodrome (erstmalig)
  • HTML-Re-Scrape technisch machbar (Permalinks via Playwright erreichbar)
  • Wenn irgendein Punkt nicht erfüllt → STOP, Alternativen bewerten

Gate β — vor Phase 5 (Frequenzen)

  • F1 ≥ 0.99 auf CRITICAL-Runways in Phase 4
  • Review-UI funktional und von einem Piloten getestet
  • Adversarial-Set besteht 10/10
  • Cost-Cap-Mechanismus verifiziert

Gate γ — vor GA (Phase 8)

  • Alle 6 Safety-Sign-Off-Punkte (§19 der Iterationen) erfüllt
  • Top-10-Flughäfen manuell gegen die AIP verifiziert
  • Legal-Approval des Banners
  • Beacon-Drift-Alert läuft
  • Rollback-Plan dokumentiert

Hard No-Go-Kriterien (jederzeit)

  • Irgendein Critical-Wert wird einmal ohne 3/3-Konsens öffentlich sichtbar → sofortiger Freeze
  • F1 auf CRITICAL fällt unter 0.97 nach einem Deploy → Rollback
  • Adversarial-Test meldet unerwartete Werte → Freeze bis Prompt-Fix
  • Beacon-Drift > 5 % Abweichung → Freeze + Incident-Review

15Finale Validierungs-Checkliste (post-GA)

  • Kein UI-Feld zeigt CRITICAL-Werte ohne reviewed_by IS NOT NULL
  • AIRAC-Zyklus-Wechsel flippt extraction_stale = true automatisch
  • UI zeigt X-Aerofly-Derived: true Header und den Banner

  • Beacon-PNG täglich verarbeitet, Dashboard grün
  • Kosten-Cap-Alerts bei 50 % / 75 % / 100 % des monatlichen Budgets
  • Review-Queue leert sich regelmäßig (SLA: ≤ 48 h)
  • Legal-Text unverändert seit Approval
  • Kein API-Key in Git-Historie (pre-commit-Hook aktiv)
  • Rollback-Runbook aktuell und getestet
