Plan · Chart Thumbnail Grid v1

Feature design & implementation plan — replacing the expandable chart list on the aerodrome detail view with a visual thumbnail grid.

2026-04-19 target: develop Progress: 94 % Status: AWAITING GO

01Executive summary

  • What: Replace the chart list in the aerodrome detail page with a thumbnail grid grouped by chart type. Clicking a thumbnail opens the existing pan-zoom viewer (already shipped in #17).
  • Why: Pilots recognise aviation charts visually faster than by title. Three seconds becomes one.
  • Scope: Frontend-only. Re-uses the already-imported 1042 preview PNGs. No backend or schema change.
  • Risk: Low — localised UI change on one page with a one-file rollback path.
  • Safety invariants: AIRAC cycle visible on every card and in hero; image-load fallback preserves the fact that a chart exists; "reference only" banner once per page.

03Deep-dive analysis

Current state

Detail page AerodromeDetail.tsx renders each chart as a row inside ChartItem.tsx (<li class="chart-item">). The row exposes a chevron, file icon, title, expand button and DFS link. Clicking the row expands the preview inline; clicking the preview opens ChartViewer.

Pain point: the user must read each title (cognitively slow) and at best expand to confirm. For aerodromes with ≥ 4 charts this adds real friction.

Proposed state

Detail page renders a grouped thumbnail grid. Each card shows the chart preview (fit, not cropped), a chart-type badge, the title (truncated to 2 lines) and an AIRAC mini-label. Click anywhere on the card opens ChartViewer. Keyboard: tab + arrows navigate, Enter/Space opens, viewer Esc returns focus.

ChartItem.tsx becomes unused and is deleted in the same PR after E2E is green.

Rollback plan

The change is concentrated in one JSX block inside AerodromeDetail.tsx. If a regression is detected after merge:

git revert <merge-sha>
docker compose restart frontend

Restores the pre-thumbnail list in under two minutes. Until E2E is green, ChartItem.tsx is kept in the tree as an insurance branch; it is deleted only in the final commit of the PR.

E2E (Playwright)

Five scenarios — new file services/frontend/tests/e2e/chart-grid.spec.ts 
import { test, expect } from "@playwright/test";

test.describe("chart thumbnail grid", () => {
  test("EDDF renders N thumbnails matching API", async ({ page, request }) => {
    const res  = await request.get("http://localhost:8080/api/aerodromes/EDDF");
    const data = await res.json();
    await page.goto("http://localhost:8080/aerodromes/EDDF");
    const cards = page.getByRole("button", { name: /chart/i });
    await expect(cards).toHaveCount(data.charts.length);
  });

  test("clicking a thumbnail opens the viewer with print variant", async ({ page }) => {
    await page.goto("http://localhost:8080/aerodromes/EDDF");
    await page.getByRole("button", { name: /terminal chart/i }).first().click();
    await expect(page.getByRole("dialog")).toBeVisible();
    await expect(page.locator('img[src*="_print"]')).toBeVisible();
  });

  test("Esc in viewer returns focus to the opened card", async ({ page }) => {
    await page.goto("http://localhost:8080/aerodromes/EDDF");
    const card = page.getByRole("button", { name: /terminal chart/i }).first();
    await card.focus();
    await page.keyboard.press("Enter");
    await expect(page.getByRole("dialog")).toBeVisible();
    await page.keyboard.press("Escape");
    await expect(page.getByRole("dialog")).toBeHidden();
    await expect(card).toBeFocused();
  });

  test("keyboard grid navigation", async ({ page }) => {
    await page.goto("http://localhost:8080/aerodromes/EDDF");
    await page.getByRole("button", { name: /chart/i }).first().focus();
    await page.keyboard.press("ArrowRight");
    await expect(page.getByRole("button", { name: /chart/i }).nth(1)).toBeFocused();
  });

  test("404 on image falls back to icon, card still clickable", async ({ page }) => {
    await page.route("**/api/charts/EDDF/EDDF_Frankfurt_Main_1_preview.png",
      r => r.fulfill({ status: 404 }));
    await page.goto("http://localhost:8080/aerodromes/EDDF");
    const failedCard = page.getByRole("button", { name: /frankfurt main 1/i });
    await expect(failedCard).toBeVisible();
    await failedCard.click();
    await expect(page.getByRole("dialog")).toBeVisible();
  });
});
